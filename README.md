Кофейный аппарат (Вариант 2)
Консольное приложение на C# (.NET 6+), которое показывает работу паттернов Декоратор и Абстрактная фабрика.

Что делает программа:
Создает напитки.
Добавляет к ним добавки и пересчитывает цену.
Собирает готовые наборы через фабрики.

Какие паттерны использованы:
Decorator — чтобы добавлять добавки к напиткам, не создавая кучу классов типа ЭспрессоСМолокомИСахаром. Просто оборачиваем объект в декоратор.
Abstract Factory — чтобы создавать готовые наборы. Если завтра понадобится новое меню, мы просто создадим новую фабрику, а старый код трогать не придется.

Запуск
1.Нажмите зеленую кнопку <> Code.
2.Перейдите на вкладку Codespaces и нажмите Create codespace on main.
3.Подождите пару минут, пока среда загрузится.
4.Введите в терминал команду: dotnet run
